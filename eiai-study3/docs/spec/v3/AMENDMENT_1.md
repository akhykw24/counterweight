# Amendment 1 to the v3 specification — order of the closing measures

`docs/spec/v3/SPEC.md` is Appendix A of the approved brief and stays verbatim.
This file records a change to it, decided by the researcher after the pilot
(October 2026).

## What changed

**Procedure, as specified:** … final quiz → tutor evaluation → awareness
funnel → explanation-quality check → (NCS-6) → demographics → debriefing,
with P1–P6 asked before the training.

**Procedure, as amended:** consent → screening → **P1–P3** → allocation →
3 modules → final quiz → **awareness funnel F1–F4** → tutor evaluation
(T, R, E) → explanation-quality check (E6) → **P4–P6** → (NCS-6) →
demographics → (pilot feedback) → debriefing.

No item wording changed. Only positions moved.

## Why

In the pilot, two of three completers named the purpose almost exactly
("How much users trust AI"; "whether people read a whole passage"). Two
features of the order told them:

- P4–P6 (trust in AI) were the first questions after screening, so the topic
  "trust in AI" was named before any training began.
- The tutor evaluation (T1–T4: "warm", "emotionally supportive") came before
  the funnel, so by the time F1–F3 asked what the study was about, the
  participant had just been asked about Nova's warmth.

A funnel debriefing is valid only if nothing before it has suggested the
hypothesis (Bargh & Chartrand, 2000); measures that name the manipulation
are demand cues in Orne's (1962) sense. Moving the funnel directly after the
last task measure, and everything that names warmth, trust or evidence after
the funnel, removes both cues without changing any wording.

## Cost, stated

P4–P6 were listed as covariates (SPEC: "Covariates: English level (CEFR),
P1–P6"). Measured after the training, P4–P6 are post-treatment: Nova's tone
could shift them, so they should not be used as covariates in the main
analysis without checking that they do not differ by tone. P1–P3 remain
pre-treatment covariates.
