# Основное исследование v3 — инструкция

## Ссылка — одна для всех

```
https://counterweight-pearl.vercel.app/
```

Её можно разослать всем сразу и выложить куда угодно. Версию каждому
выбирает сервер, по очереди, из заранее зафиксированной случайной
последовательности:

- последовательность составлена **блоками по 4**: в каждом блоке все четыре
  версии ровно по одному разу. Поэтому версии всегда поровну, с точностью до
  одного неполного блока;
- отдельные последовательности для двух уровней английского (B1–B2 и
  C1–C2/носители), поэтому и внутри каждого уровня версии поровну;
- двое, начавшие одновременно, всё равно получат разные места: сервер выдаёт
  их по одному;
- если человек перезагрузил страницу или пропала связь — он получит то же
  место, а не новое;
- версия выдаётся только после отбора и вопросов P1–P6. Кого не пустил отбор,
  тот места не занимает.

Последовательность и её отпечаток (`sequence_sha256`) записаны в
`docs/allocation-v3-precommit.txt` **до** начала сбора: по ним любой может
проверить, что распределение не подгоняли.

Человек, который бросил после получения версии, место всё равно занимает —
так и должно быть при блочной рандомизации.

Пилотные ссылки (`?pilot=true&p=1` …) продолжают работать по-старому и в
основную последовательность не попадают.

## Как посмотреть, сколько людей уже начали

Откройте в браузере:

```
https://counterweight-pearl.vercel.app/api/allocate
```

Это счётчик: сколько мест занято в каждом уровне английского. Какая версия
будет следующей, он не показывает.

- `B1-B2` и `C1-C2-native` — настоящие участники;
- `test:...` — тестовые прохождения (мои и ваши).

Сколько человек **дошли до конца** — в Supabase → **SQL Editor**:

```sql
select max(cell) as version,
       count(distinct session_id) filter (where type = 'allocation')        as started,
       count(distinct session_id) filter (where type = 'session_completed') as finished,
       count(distinct session_id) filter (where type = 'withdrawal_requested') as removed
from public.events
where run_mode = 'live' and participant_id is not null
group by cell
order by cell;
```

### Сколько ответов годные

Запрос `docs/sql/main_v3_status.sql` — скопировать целиком в SQL Editor →
Run. Он ничего не меняет, только считает. Строка на каждую версию и итог
`ALL`:

| Колонка | Что значит |
|---|---|
| `started` | получили версию |
| `finished` | дошли до конца |
| `usable` | **годные**: дошли до конца, не удалили данные, прошли проверку внимания, выбрали ловушку меньше 4 раз из 12, участвуют впервые |
| `failed_attention` | не прошли проверку внимания |
| `distractor_4_plus` | выбрали ловушку 4+ раз — отвечали наугад |
| `repeat` | повторное прохождение |
| `removed_data` | нажали «Remove my data» |
| `usable_under_8_min` | годные, но прошли быстрее 8 минут — порог «слишком быстро» ещё не утверждён, это только для просмотра |
| `usable_avg_minutes` | среднее время у годных |

Сколько людей не прошли отбор:

```sql
select payload->>'reason' as reason, count(*) as people
from public.events
where run_mode = 'live' and type = 'screened_out'
group by 1;
```

`age` — младше 18, `language` — английский ниже B1.

## Как проверить самой, ничего не испортив

```
https://counterweight-pearl.vercel.app/?test=true
```

Это точная копия ссылки для участников, но всё помечено `test`, и версия
берётся из отдельной тестовой очереди: место настоящего участника не
занимается. Чтобы пройти заново — откройте в приватном окне.

Чтобы посмотреть конкретную версию: `?test=true&cell=EI-A` (или `EI-B`,
`Neutral-A`, `Neutral-B`).

**Не проходите сами простую ссылку без `?test=true`** — такое прохождение
считается настоящим участником.

## Выгрузка данных

Как в пилоте (`docs/PILOT_V3_RU.md`, раздел 3), только с `--mode live`:

```bash
python pipeline/v3_export.py --events data/main-v3-events.csv --mode live --out results/export_main_v3
```

В `participants_wide.csv` у каждого участника есть `cell` (версия) и
`sequence_index` (номер места в последовательности). Кто нажал «Remove my
data», исключён целиком.

## Как закрыть набор

Когда участников достаточно: Vercel → проект → **Settings → Environment
Variables** → добавить `VITE_V3_LIVE` = `closed` → **Redeploy**. Ссылка начнёт
показывать «This study is not open yet.». Тестовые и пилотные ссылки
продолжат работать. Чтобы открыть снова — удалить переменную и снова
Redeploy.

## Если участник пишет об ошибке

Всё как в пилоте (`docs/PILOT_V3_RU.md`, раздел 5), плюс:

| Жалоба | Что ответить |
|---|---|
| «Висит “Connecting…” после вопросов» | Нет интернета или сервер не отвечает. Страница сама повторяет попытку — подождать минуту. Если не помогло — перезагрузить: место сохранится. |
| «Пишет “This study is currently full”» | Последовательность закончилась (400 мест на уровень английского). Напишите мне. |
